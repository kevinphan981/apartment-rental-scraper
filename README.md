# About
A scraper built to retrieve rental data from common listing sites.

The idea is that I have to learn how to properly webscrape, and then develop a solution (probably browser automated with proxies) in order to webscrape what I need off of one of the following: Redfin, Apartments.com, Zillow, or Craigslist. 

I've now realized that I need to do something automated with this using a VPS.

This is actually a sub-project for what I need, which is rental data to evaluate the effects of property taxes via the pass-through effect.
